What this demo does—and doesn't do

      
Implemented: a playable browser GridWorld, optional local Python HTTP API, seeded tabular
        Q-learning, real training windows, frozen-policy evaluation versus a random baseline,
        and downloadable run data.

      
Not implemented: Unity, ML-Agents, PyTorch, PPO, DQN, neural networks,
        TensorBoard, or generalization to unseen maps. This deliberately small educational
        demo is not evidence of those resume claims. There is no simulated “deep RL” or hidden
        pretrained policy.
